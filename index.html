📋
ขั้นตอนการเชื่อมต่อ Google Sheets ใน 3 ขั้นตอน

ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องสมัคร API เสียเงิน รองรับการแชร์และทำงานร่วมกันได้ฟรี 100%

  1. สร้างไฟล์ Google Sheets ใหม่ที่ sheets.new
  2. ไปที่เมนูด้านบน ส่วนขยาย (Extensions) > Apps Script ลบโค้ดเดิมทั้งหมด แล้วนำโค้ดด้านล่างนี้ไปวาง
  3. กดปุ่ม ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้ใหม่ (New deployment) > เลือกประเภทเป็น เว็บแอป (Web app) > ตั้งค่า ผู้มีสิทธิ์เข้าถึง (Who has access) เป็น ทุกคน (Anyone) > กดทำให้ใช้งานได้ แล้วคัดลอก URL เว็บแอป มาวางในช่องด้านบนได้ทันที!
